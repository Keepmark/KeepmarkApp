          About
          
        
          Keepmark is an independent client, not affiliated with xBrowserSync.
          It speaks the open xBrowserSync API and is interoperable with the official apps.

          Compatibility
          
        
            
          
          • Legacy contract xBrowserSync API … always supported
            (official, self-hosted or community services, API …+ required).
            • 
          
          • Extended contract Keepmark API …
            (revision CAS, conditional pull, server-side delete): used automatically when
            the service advertises it; legacy services fall back to v1.1.
            • 
          
          • Sync format …: syncs created here
            open in the official xBrowserSync apps, and vice versa.
            • 
          
          • Same end-to-end encryption (PBKDF2-SHA256 + AES-GCM): only your password
            unlocks the data — the service operator cannot read it.
