              Danger zone

              Backup

              Export

              Save this browser's bookmarks to an encrypted file in your downloads. Choose a backup password of at least 8 characters. It is not your sync password and cannot be recovered: without it the file cannot be opened.

              Restore from a backup file

              Replaces this browser's bookmarks and the server copy; your other devices get the backup at their next sync. The current bookmarks are saved to Safety backups first.

              Restoring a backup needs a linked sync: it is uploaded right after. Connect from the Keepmark popup first.

              Safety backups

              Automatic snapshots taken before every overwrite or deletion (newest 5 kept). Encrypted entries need the current sync link to restore.

              Duplicate bookmarks

              Same URL saved more than once. Mark copies to delete — one copy of each URL always stays. Click a title to open it.

              Move to another service

              Move your bookmarks to a different service, into a new or an existing sync. Anything replaced is saved to Backup → Safety backups first.

              Moving needs a linked sync. Connect from the Keepmark popup first.

              Change password
              
        
              Re-encrypts the sync with a new password (at least 8 characters). Your current password is verified first and never leaves this device. The old password stops working on every device at once.
              
        
              Changing the password needs a linked sync. Connect from the Keepmark popup first.
              
        
        
        
        
              
        
              
        
              
      
              

      
              
        
              About
              
        
              Keepmark is an independent client, not affiliated with xBrowserSync.
          It speaks the open xBrowserSync API and is interoperable with the official apps.
              
        
              Keepmark …
              
        
              Compatibility
              
        
                
          
              • Legacy contract xBrowserSync API … always supported
            (official, self-hosted or community services, API …+ required).
                • 
          
              • Extended contract Keepmark API …
            (revision CAS, conditional pull, server-side delete): used automatically when
            the service advertises it; legacy services fall back to v1.1.
                • 
          
              • Sync format …: syncs created here
            open in the official xBrowserSync apps, and vice versa.
                • 
          
              • Same end-to-end encryption (PBKDF2-SHA256 + AES-GCM): only your password
            unlocks the data — the service operator cannot read it.
