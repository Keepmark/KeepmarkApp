                A copy of this browser's bookmarks, taken in the background only when they have changed. It is stored in this browser, next to the safety backups: restore one from Backup. Removing the extension removes the copies too. While no sync is linked the copy is not encrypted.

                Only for troubleshooting: the log stays in this browser and is never uploaded.

                
          
                
        
                
      
                

      
                
        
                About
                
        
                Keepmark is an independent alternative compatible with xBrowserSync: private, end-to-end encrypted bookmark sync that works with any xBrowserSync service (official, self-hosted or community) and with the official xBrowserSync apps. Not affiliated with or endorsed by xBrowserSync.
                
        
                Keepmark …
                
        
                Compatibility
                
        
                  
          
                • Legacy contract xBrowserSync API … always supported (official, self-hosted or community services, API …+ required).
                  • 
          
                • Extended contract Keepmark API …
            (revision CAS, conditional pull, server-side delete): used automatically when the service advertises it; legacy services fall back to v1.1.
                  • 
          
                • Sync format …: syncs created here open in the official xBrowserSync apps, and vice versa.
                  • 
          
                • Same end-to-end encryption (PBKDF2-SHA256 + AES-GCM): only your password unlocks the data — the service operator cannot read it.

                Connect Keepmark on your phone
                
        
                In Keepmark for Android, open Connect → Existing sync → Scan QR from browser.
                
        
                
        
                
          
          
                
            
            
            
          
                
          
                
        
                
        
                
        
                
        
                The QR contains your service, sync ID and the sync key (not your password). Anyone with a copy can read and change these bookmarks. It is hidden after 60 seconds or when you leave this view. Set a sync lock to ask a password first.
                
        
                      
    
                
    
    
      
                
        
                Sync lock
                
        
                It protects every saved sync, so it is asked once before adding starts.
                
        
                
          
          
          
                
            
            
          
                
          
                
        
                
      
                
      
                
        
                
          
                Add a sync
                
          
        
                
        
                Create a new sync or open one you already use on another device. Adding a sync
          while another is active switches this browser to it; the old sync stays in the list.
                
        
        
                
          Which sync?
          
          
        
                
        
        
        
                Another sync already uses this name: choose a different one.
                
        
                
        
        
        
                At least 8 characters. It encrypts the new sync and cannot be recovered.
                
        
                The new sync starts with the bookmarks currently in this browser.
          The sync you are using now stays in the list.
                
        
                There is an unresolved conflict: the new sync will start from
          the bookmarks in this browser, while the conflicted sync keeps its server copy.

                Export
                
      
                
        
                Save this browser's bookmarks to an encrypted file in your downloads. Choose a backup
          password of at least 8 characters. It is not your sync password and cannot be recovered: without it the
          file cannot be opened.
                
        
        
        
                
          
          
        
                
        
                
      
                
                    
    
      
                Bookmarks file (HTML)
                
      
                This file is NOT encrypted: anyone who opens it can read every bookmark, tag and
        description. Keep it private and delete it once imported.
                
      
                
        
        
      
                
      
                
                    
    
      
                Restore from a backup file
                
      
                
      
                Replaces this browser's bookmarks and the server copy; your other devices get the backup at
        their next sync. The current bookmarks are saved to Safety backups first.
                
      
                
        
                
          
          
                
        
                
        
                
        
                
          
          
        
                
        
                
      
                
                    
    
      
                Change password
                
      
                
      
                
        
        Your other devices stop syncing until you unlink them and link again with the new password. Edits not yet synced are uploaded now. Older backup files keep their own password.
      
                
      
                
        
                At least 8 characters. Your current password is verified first and never leaves this device.
